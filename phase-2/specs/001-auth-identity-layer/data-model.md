## Entity Definitions

### User

**Purpose**: Represents a registered user of the system.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | string (UUID) | PRIMARY KEY | Unique identifier, generated by Better Auth |
| email | string | UNIQUE, NOT NULL, max 255 | User's email address (normalized to lowercase) |
| emailVerified | boolean | DEFAULT false | Whether email has been verified (always false in MVP) |
| name | string | NULL | Optional display name |
| image | string | NULL | Optional profile image URL |
| createdAt | datetime | NOT NULL | Account creation timestamp |
| updatedAt | datetime | NOT NULL | Last update timestamp |

**Validation Rules**:
- Email must be valid format (RFC 5322)
- Email normalized to lowercase before storage
- Email must be unique across all users

**Note**: Better Auth manages this table automatically. The backend reads from it but does not write directly.

---

### Account

**Purpose**: Stores authentication credentials for a user.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | string (UUID) | PRIMARY KEY | Unique identifier |
| userId | string | FOREIGN KEY → User.id | Link to user |
| accountId | string | NOT NULL | Provider-specific account ID |
| providerId | string | NOT NULL | Authentication provider ("credential") |
| password | string | NULL | Hashed password (bcrypt) |
| createdAt | datetime | NOT NULL | Record creation timestamp |
| updatedAt | datetime | NOT NULL | Last update timestamp |

**Validation Rules**:
- Password must be minimum 8 characters (validated before hashing)
- Password hashed using bcrypt with cost factor 10+
- providerId is "credential" for email/password auth

**Note**: Better Auth manages this table. Password is never stored in plaintext.

---

### Session

**Purpose**: Tracks active user sessions.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | string (UUID) | PRIMARY KEY | Unique identifier |
| userId | string | FOREIGN KEY → User.id | Link to user |
| token | string | UNIQUE, NOT NULL | Session token |
| expiresAt | datetime | NOT NULL | Session expiration time |
| ipAddress | string | NULL | Client IP address |
| userAgent | string | NULL | Client user agent string |
| createdAt | datetime | NOT NULL | Session creation timestamp |
| updatedAt | datetime | NOT NULL | Last update timestamp |

**Note**: Better Auth manages sessions. The JWT token is derived from session but verified independently.

## Runtime Objects (Not Persisted)

### JWT Token Payload

**Purpose**: Claims encoded in the JWT token issued by Better Auth.

```typescript
interface JWTPayload {
  sub: string;      // User ID (maps to User.id)
  email: string;    // User email
  iat: number;      // Issued at (Unix timestamp)
  exp: number;      // Expires at (Unix timestamp)
}
```

**Validation Rules**:
- `sub` must be non-empty string
- `email` must be valid email format
- `exp` must be in the future (token not expired)
- Signature must be valid (verified with JWT_SECRET)

---

### CurrentUser (Backend Runtime)

**Purpose**: Authenticated user context available to API handlers.

```python
class CurrentUser:
    id: str       # User ID from token.sub
    email: str    # User email from token.email
```

**Source**: Extracted from verified JWT token payload.

**Usage**: Injected via FastAPI dependency into protected route handlers.

---

### AuthSession (Frontend Runtime)

**Purpose**: Client-side authentication state.

```typescript
interface AuthSession {
  user: {
    id: string;
    email: string;
    name?: string;
  };
  token: string;  // JWT for API calls
}
```

**Source**: Better Auth session management.

**Usage**: Available via `useSession()` hook.

## Database Schema (SQL)

Better Auth auto-generates these tables. For reference:

```sql
-- Users table
CREATE TABLE "user" (
    id TEXT PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    "emailVerified" BOOLEAN DEFAULT FALSE,
    name TEXT,
    image TEXT,
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

-- Accounts table (credentials)
CREATE TABLE account (
    id TEXT PRIMARY KEY,
    "userId" TEXT NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    "accountId" TEXT NOT NULL,
    "providerId" TEXT NOT NULL,
    password TEXT,
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

-- Sessions table
CREATE TABLE session (
    id TEXT PRIMARY KEY,
    "userId" TEXT NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    token TEXT UNIQUE NOT NULL,
    "expiresAt" TIMESTAMP NOT NULL,
    "ipAddress" TEXT,
    "userAgent" TEXT,
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_user_email ON "user"(email);
CREATE INDEX idx_account_user ON account("userId");
CREATE INDEX idx_session_user ON session("userId");
CREATE INDEX idx_session_token ON session(token);
```

## Entity Relationships

| Relationship | Type | Description |
|--------------|------|-------------|
| User → Account | 1:N | One user can have multiple auth providers |
| User → Session | 1:N | One user can have multiple active sessions |
| Account → User | N:1 | Each account belongs to one user |
| Session → User | N:1 | Each session belongs to one user |

## State Transitions

### User Lifecycle

```
[Anonymous Visitor]
        │
        │ POST /api/auth/signup (email, password)
        ▼
[Registered User] ──────────────────────────────┐
        │                                        │
        │ POST /api/auth/signin (email, password)│
        ▼                                        │
[Authenticated User] ◄───────────────────────────┘
        │                 Token expired: re-authenticate
        │
        │ POST /api/auth/signout
        ▼
[Signed Out User] (returns to Registered User state)
```

### Token Lifecycle

```
[No Token]
    │
    │ Successful signin/signup
    ▼
[Valid Token] ─────────────────────────────────┐
    │                                           │
    │ Time passes                               │ API request
    ▼                                           ▼
[Expired Token]                           [Token Verified]
    │                                           │
    │ Any API request                           │ Extract user context
    ▼                                           ▼
[401 Unauthorized]                        [Request Processed]
```
